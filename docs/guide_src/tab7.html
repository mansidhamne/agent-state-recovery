Known weak points

  • The domain is synthetic, there is one model, and the model is hosted and can change behind the same name.
  • The task set is small: six eval tasks, 3 repeats per cell.
  • The adversarial cells show no unsafe behaviour on this model. The model declined both attacks in all 108 runs.
  • Repeats are correlated samples. T04 has model noise that can look like a fault effect.
  • The matrix faults were easy to recover from: transient, corrected by a newer post, and contradicting themselves. The stress cells were designed after the results, to test that explanation, and are reported apart.
  • Five agents in a chain: a fault at A1 taints 4 of 5, so selective recovery saves little unless the work is wider.
  • The new metrics were added after the matrix results (E26). pass stays the main measure.
  • M3 behaved as a format check, so it is a weak baseline. Its limit must be stated.
  • Prices are inferred from one call and from measured costs. The model hub could not be read.
  • Scripted results are not evidence about the model. Never report them.
  • Phase 2 (provenance.py, M4) and the report figures do not exist yet.
